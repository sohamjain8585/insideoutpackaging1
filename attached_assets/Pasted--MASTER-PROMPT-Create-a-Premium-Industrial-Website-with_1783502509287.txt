# MASTER PROMPT — Create a Premium Industrial Website with Modern Animations

Act as a senior UI/UX designer, award-winning frontend developer, motion designer, and performance engineer.

Build a completely original website that captures the premium feel, smooth interactions, and polished motion of a modern industrial B2B website. Do **not** copy source code, images, logos, text, or proprietary assets from any existing website. Recreate only the overall animation quality and user experience.

## Tech Stack

* React + Next.js
* TypeScript
* Tailwind CSS
* Framer Motion
* GSAP (ScrollTrigger where appropriate)
* Lenis smooth scrolling
* Three.js (optional for subtle background effects)
* SVG animations
* Fully responsive
* Lighthouse Performance 95+
* WCAG accessibility compliant

---

## Overall Motion Style

The entire experience should feel:

* Premium
* Fast
* Smooth
* Minimal
* Professional
* Industrial
* Modern
* Confident

Use motion purposefully. Every animation should improve usability rather than distract.

Animation timing:

* Duration: 0.3–0.8 seconds
* Ease: cubic-bezier(0.22, 1, 0.36, 1)
* Stagger: 60–120 ms
* 60 FPS target
* Hardware-accelerated transforms only
* Animate opacity and transform instead of layout properties
