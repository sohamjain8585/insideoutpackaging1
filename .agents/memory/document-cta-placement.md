---
name: Document CTA placement
description: Placement rule for the public Catalogue and Company Profile download actions.
---

Keep the Catalogue PDF and Company Profile PDF actions together in the home-page hero beside the Explore Products and Request a Quote buttons. Do not add separate download sections elsewhere unless the user asks.

**Why:** The user explicitly corrected the placement and asked to remove the other copies.

**How to apply:** When changing these download actions, preserve the home-hero placement and their existing gated form behavior.
